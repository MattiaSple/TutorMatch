# TutorMatch

App Android per mettere in contatto tutor e studenti: ricerca del tutor più vicino, prenotazione delle lezioni e gestione del calendario.

Progetto universitario — Università Politecnica delle Marche.

## Tecnologie
- Kotlin (Android)

## Stato del progetto
⚠️ Il database di backend non è più collegato: l'app non è eseguibile così com'è.
Il codice resta consultabile come riferimento.
